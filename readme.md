# Emmanuel Samson Portfolio Website

Premium static portfolio website with light/dark theme toggle, portfolio filters, project modal previews, Upwork CTAs, and glassmorphism animations.

## Preview locally

Open this folder in VS Code, install **Live Server**, right-click `index.html`, then choose **Open with Live Server**.

## Deploy with GitHub + Netlify

1. Create a new GitHub repository.
2. Upload the contents of this folder to the repository.
3. In Netlify, choose **Add new project** → **Import an existing project** → **GitHub**.
4. Select the repository.
5. Because this is a static site, leave the build command empty and set publish directory to `/` or the project root.
6. Publish. Future pushes to GitHub will trigger a new Netlify deploy.
